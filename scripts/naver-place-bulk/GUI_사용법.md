# GUI 프로그램 사용법

## 실행

**`유아독존_자동등록.bat`** 더블클릭  
(또는 `launch-gui.ps1` / `python gui_app.py`)

---

## 화면 설명

### 설정 탭
| 항목 | 설명 |
|------|------|
| 사이트 URL | `https://www.yourdogzone.co.kr` |
| 관리자 비밀키 | Vercel `ACADEMY_ADMIN_SECRET` |
| 검색어 | 줄마다 1개 (`부천 애견미용학원`) |
| 검색당 최대 | 검색어당 몇 곳 수집할지 |
| Gemini | 소개글 자동 편집 (Vercel에 API 키 필요) |
| 브라우저 숨김 | 체크 해제 시 Chrome 창이 보임 |

**💾 설정 저장** → `.env` + `config.json` 저장

### 버튼
| 버튼 | 동작 |
|------|------|
| **수집 시작** | 네이버에서만 수집 → `crawled_날짜.json` 저장 |
| **수집 + 등록** | 수집 → 이미지 R2 → Gemini → 사이트 등록 |
| **JSON만 등록** | 이전 수집 파일만 다시 등록 |

### 수집 파일 탭
- 이전 `crawled_*.json` 선택 후 **JSON만 등록** 가능

---

## 최초 1회
1. Python + Chrome 설치
2. 관리자 비밀키 입력 → 설정 저장
3. 검색어 1~2개, 최대 2로 테스트
4. **수집 시작** → 잘 되면 **수집 + 등록**

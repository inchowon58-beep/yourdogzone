# 자동화 — 당신이 할 일

## 한 번만 설정

### 1. Vercel
- `ACADEMY_ADMIN_SECRET` ✅
- `GEMINI_API_KEY` ✅ (소개글 자동 편집)
- Redeploy 완료

### 2. PC — Chrome 브라우저 설치
- [Google Chrome](https://www.google.com/chrome/) 설치 (대부분 이미 있음)

### 3. `.env` (폴더 안)
```
ACADEMY_ADMIN_SECRET=Vercel과_동일한_값
```

### 4. `config.json` — 검색어만 수정
```json
{
  "searches": [
    { "query": "부천 애견미용학원", "max": 5 },
    { "query": "수원 애견미용학원", "max": 5 }
  ],
  "refine_with_gemini": true
}
```
- `query`: 네이버 지도에 칠 검색어
- `max`: 검색어당 몇 곳까지 수집할지

## 실행 (이후 매번)

1. `scripts\naver-place-bulk` 폴더 열기
2. **`auto-run.ps1`** 우클릭 → PowerShell로 실행
3. 끝날 때까지 대기 (검색 → 수집 → Gemini → 등록 자동)

## 자동으로 되는 것

| 단계 | 처리 |
|------|------|
| 네이버 지도 검색 | Selenium |
| 학원명·주소·전화·소개 수집 | Selenium |
| 사진 URL 수집 | Selenium |
| 이미지 R2 업로드 | 서버 API |
| 소개글 Gemini 재작성 | 서버 API |
| 사이트 등록 | 서버 API |

---

## 옵션 명령어

```bash
# 수집만 (등록 안 함) — 테스트용
python auto_crawl_register.py --dry-run

# 검색어 1개만 빠르게 테스트
python auto_crawl_register.py --query "부천 애견미용학원" --max 2

# 브라우저 창 보면서 디버그
python auto_crawl_register.py --query "부천 애견미용학원" --max 1 --show-browser --dry-run
```

## 주의

- 네이버 이용약관·저작권 준수 필요
- 처음엔 `max: 2` 로 소량 테스트 권장
- 이미 등록된 학원명은 자동 건너뜀
- 인증 추천 학원은 등록 후 admin 페이지에서 ON

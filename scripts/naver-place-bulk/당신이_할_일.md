# 당신이 할 일만 (3단계~)

나머지 파일·스크립트는 이미 준비되어 있습니다.

---

## 사전 확인 (Vercel, 1회)

Vercel → 프로젝트 → Settings → Environment Variables 에 아래가 있는지 확인:

- `ACADEMY_ADMIN_SECRET` ← **이 값을 아래 3-1에서 씁니다**
- R2 관련 변수들 (이미 설정됨)
- (선택) `GEMINI_API_KEY` ← Google AI Studio에서 발급 후 넣으면 소개글 자동 다듬기

설정 후 **Redeploy** 한 번.

---

## 3단계 — PC에서 실행 준비

### 당신이 할 일

1. 폴더 열기:  
   `유아독존\ua-dogzone-temp\scripts\naver-place-bulk`

2. **`run-register.ps1`** 파일을 **우클릭 → PowerShell로 실행**  
   (처음이면 `.env`, `academies.json`이 자동 생성되며 메모장이 열림)

3. **`.env` 파일** — 딱 한 줄만 수정:
   ```
   ACADEMY_ADMIN_SECRET=Vercel에_넣은_비밀키_그대로_붙여넣기
   ```
   저장 후 `run-register.ps1` 다시 실행.

> Python이 없으면 [python.org](https://www.python.org/downloads/) 에서 설치 (설치 시 "Add to PATH" 체크).

---

## 4단계 — 학원 데이터 넣기

### 당신이 할 일

**`academies.json`** 에 등록할 학원 정보를 넣습니다. (네이버 플레이스에서 복사)

| 필드 | 어디서 가져오나 |
|------|----------------|
| `name` | 플레이스 상호명 |
| `address` | 주소 |
| `phone` | 전화번호 |
| `description` | 소개/정보 탭 글 전체 |
| `image_urls` | 사진 우클릭 → 이미지 주소 복사 (여러 장 가능) |

처음엔 **1곳만** 넣고 테스트하세요.

저장 후 `run-register.ps1` 다시 실행.

---

## 5~6단계 — 등록 & 확인

### 당신이 할 일

- `run-register.ps1` 실행 → 터미널에 `✓ 학원명 → https://...` 나오면 성공
- 브라우저: https://www.yourdogzone.co.kr/services/academy
- 상단 **인증 추천**에 올리려면:  
  https://www.yourdogzone.co.kr/services/academy/admin  
  → 비밀키 입력 → **추천 ON**

---

## 당신이 저에게 전달해 주면 되는 것 (막힐 때)

1. Vercel `ACADEMY_ADMIN_SECRET` 은 **직접 Vercel에만** 넣으세요 (채팅에 보내지 마세요)
2. 등록하려는 학원 **1곳** 정보:
   - 학원명, 주소, 전화, 소개글, 네이버 이미지 URL 1~3개
3. 에러 나면: `run-register.ps1` 실행 후 **빨간 에러 메시지** 캡처

---

## Gemini API 키 (선택)

1. https://aistudio.google.com/apikey
2. Create API key
3. Vercel → `GEMINI_API_KEY` 에 붙여넣기 → Redeploy

PC `.env`에는 Gemini 키 **넣을 필요 없음** (서버에서 처리).
